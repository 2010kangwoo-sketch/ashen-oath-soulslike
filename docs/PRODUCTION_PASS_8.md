# Production Pass 8 — 재의 서약자와 두 결말

이번 차수는 세 번째 보스를 추가하는 데서 끝내지 않고, 앞선 전투에서 배운 검술·위치 판단·전장 기믹을 최종 결투와 실제 결말로 묶는다. 대형 상용 MMORPG와 동일한 자산 규모를 주장하지 않지만, 페이즈별 규칙 변화, 공격 전조, 전용 경기장, 카메라·후처리·음향과 승리 이후의 완결성을 출시작 기준으로 설계한다.

## 최종 보스 정체성

재의 서약자는 플레이어와 같은 체급의 여성 검사다. 거대한 괴수 대신 자신의 이동과 검술을 되비추는 상대를 배치해, 마지막 전투가 이미 배운 기본기의 시험이 되게 한다.

- 1페이즈 `검과 검`: 절제된 3연격, 추격 찌르기, 반격, 방어 파괴
- 2페이즈 `되비치는 잔상`: 이동 방향을 읽는 순간 이동, 교차 실선, 잔상 협공과 회전 검격
- 3페이즈 `마지막 서약`: 왕관 낙하, 도넛형 안전지대, 전장 절단과 장기 연속 검격
- 총 12개 공격 데이터와 페이즈별 별도 선택 규칙
- 패링과 자세 피해는 유효하지만 마지막 페이즈에서 저항이 높아짐

## 재의 왕좌

공허한 종의 심장 뒤에 마지막 서약의 다리와 원형 왕좌 경기장을 연결했다. 여덟 개의 기둥과 깨진 거울, 룬 바닥, 왕좌 계단, 왕관 파편과 마지막 안개문이 보스 상태에 따라 반응한다. 보스 격파 후 왕좌의 핵이 활성화되고 두 결말 제단이 나타난다.

## 두 결말

- `서약을 계승한다`: 다음 순례자를 위해 불을 남기는 결말
- `서약을 끊는다`: 왕좌와 종의 명령을 끝내고 자유로운 새벽을 맞는 결말

결말 선택 후 전투 입력을 잠그고 마우스 고정을 해제한다. 선택에 따라 색감·채도·비네트·음향·문구가 달라지며, 이야기 문장 뒤에 크레디트가 이어진다.

## 검증 범위와 남은 한계

29개 TypeScript 파일의 구문, 상대 경로, 최종 보스 공격·페이즈 데이터, 결말 UI 요소, 경기장 상태 전달과 번들 fast-forward를 검증한다. 실제 브라우저에서의 난이도, 프레임 유지, 카메라 흔들림과 패턴 가독성은 Pass 9와 Pass 10의 실기 조정 대상으로 남긴다.
