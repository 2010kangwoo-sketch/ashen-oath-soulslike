# Production Pass 4 — 여성 서약지기와 2차 움직임

이번 차수는 기존 기사 리그의 체형만 축소하는 방식이 아니라, 플레이어 주인공을 여성 서약지기로 다시 설계하고 전투 가독성을 해치지 않는 범위에서 얼굴, 머리카락, 골반·흉곽·관절 몸짓을 구체화한다.

## 캐릭터 실루엣

- 좁은 허리와 안정적인 하체 중심을 가진 여성 검사 비율
- 얼굴과 눈이 읽히는 반가면 구조
- 흉곽, 골반, 어깨가 서로 다른 시간차로 회전하는 전신 리그
- 팔꿈치와 무릎 관절을 분리해 막대 인형 같은 움직임 완화
- 전투성을 유지하는 층형 판금, 천 치마, 다중 망토 패널

## 머리카락

머리카락은 하나의 판이나 동일한 사인파로 움직이지 않는다.

- 짧은 앞머리 3묶음
- 좌우 옆머리 2묶음
- 후두부 층형 머리 3묶음
- 금속 고리로 묶은 긴 꼬리 1묶음
- 각 묶음은 2~7개의 관절과 서로 다른 관성·강성·감쇠를 가짐
- 이동 속도, 가속·급정지, 회전, 낙하, 구르기, 공격, 피격, 차지 동작에 독립적으로 반응
- 관절별 각도 제한으로 얼굴 관통과 과도한 떨림을 억제

## 몸짓

- 대기 호흡, 미세한 고개 기울임, 불규칙한 시선 이동과 눈 깜빡임
- 걷기·달리기에서 골반과 흉곽의 반대 회전
- 팔꿈치와 무릎 굽힘을 포함한 보행
- 공격마다 골반 선행, 흉곽 추종, 머리 시선 고정의 순서 적용
- 방어·패링·차지·처형에 별도 전신 자세 적용
- 구르기와 피격 중 머리, 망토, 머리카락의 후행 반응

## 품질 원칙

여성 캐릭터라는 이유로 공격 거리, 이동 속도, 충돌체 또는 힘 전달을 약화하지 않는다. 외형 표현은 전투 판정과 일치해야 하며, 머리카락과 의상은 시각적 지연만 제공하고 입력 지연을 만들지 않는다.
