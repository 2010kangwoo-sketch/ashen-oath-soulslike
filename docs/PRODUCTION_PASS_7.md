# Production Pass 7 — 종을 삼킨 과부

이번 차수는 첫 보스의 검격 패턴을 재활용하지 않고, 수직 이동과 전장 기믹을 중심으로 완전히 다른 두 번째 보스전을 만든다. 대규모 상용 MMORPG와 동일한 인력·자산 규모를 주장하지 않으며, 대신 그 장르에서 중요한 전조의 가독성, 기믹 단계 변화, 카메라 프레이밍, 전장 반응을 브라우저 기반 단일 플레이 게임의 범위 안에서 구현한다.

## 보스 정체성

종을 삼킨 과부는 인간형 검사가 아니라 여덟 다리와 여러 팔을 가진 비인간형 보스다. 1페이즈에는 천장과 지상을 오가며 세 개의 종에서 힘을 공급받고, 2페이즈에는 종이 모두 파괴되거나 체력이 임계점에 도달하면 실과 공명을 직접 폭주시킨다.

## 전용 공격과 기믹

- 천장 낙하: 바닥 그림자가 고정된 뒤 낙하한다.
- 절단의 실: 긴 직선 판정 여러 개가 경기장을 분할한다.
- 종의 공명: 세 종을 중심으로 서로 다른 반경의 파동이 발생한다.
- 몸통 휩쓸기: 가까운 플레이어를 넓게 밀어낸다.
- 세 번의 장송: 천장에서 연속 낙하 지점을 만들어 이동 방향을 읽는다.
- 실창: 폭이 좁고 긴 직선 공격으로 원거리 안전지대를 압박한다.
- 과부의 돌진: 측면 이동 뒤 빠르게 거리를 좁힌다.
- 끊어진 자장가: 안쪽과 바깥쪽이 안전한 도넛형 전장 공격이다.

세 개의 종은 별도의 체력을 가진 파괴 대상이다. 종을 파괴하면 1페이즈의 방어력이 약화되고 모든 종이 끊어지면 2페이즈가 즉시 시작된다.

## 전장과 카메라

문지기 바르칸 경기장 북쪽에 끊어진 종의 회랑과 공허한 종의 심장을 연결했다. 경기장은 높은 기둥, 천장 실, 매달린 종과 다층 조명으로 수직성을 보여 준다. 천장 보스를 록온할 때 카메라는 보스 중심을 그대로 따라 올려 바닥 전조를 놓치지 않도록, 플레이어와 바닥 사이에 가중된 목표점을 사용하고 거리를 제한적으로 늘린다.

## 시각·음향 연출

- 레이드 기믹 이름, 대응 힌트와 진행 막대
- 보스별 페이즈·보조 자원 이름과 전환 문구
- 위험 기믹 중 색수차·비네트·블룸과 화면 대비의 단계적 강화
- 실 절단음, 종 공명, 전장 경고음과 2페이즈 전환음
- 종 파괴 파편과 천장 낙하 그림자

## 검증 범위와 남은 한계

코드 구조, TypeScript 타입, 공격 판정 종류, 보스 상태 초기화, 번들 병합을 검증한다. 실제 난이도, 프레임 드롭, 카메라 멀미, 브라우저별 WebGL 차이는 실기 플레이 테스트가 필요하다. Pass 8에서는 최종 보스와 결말을 구현하면서 두 보스에서 축적한 기믹 가독성과 카메라 규칙을 함께 회귀 검증한다.
