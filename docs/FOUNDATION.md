# Ashen Oath 기술 기반

## 목표

- 설치형 게임 엔진 없이 최신 데스크톱 브라우저에서 실행한다.
- `main` 브랜치는 항상 배포 가능한 상태를 유지한다.
- 10차 결과물은 기술 데모가 아니라 엔딩과 크레딧까지 있는 짧은 완결형 게임이다.
- 넓이보다 전투 판정, 카메라, 보스 패턴, 아트 통일성을 우선한다.

## 고정 기술

- Three.js: 렌더링, 후처리, 메시, 카메라, 조명
- TypeScript: 행동 상태와 전투 데이터의 타입 안정성
- Rapier 3D compat: 충돌, 키네마틱 캐릭터, 강체
- Vite: 개발 서버와 정적 빌드
- GitHub Actions + Pages: 자동 검증과 웹 배포

## 코드 구조

- `src/core`: 게임 생명주기와 프레임 루프
- `src/render`: 렌더러와 후처리
- `src/physics`: 고정 스텝 물리 세계
- `src/player`: 플레이어 제어와 시각 리그
- `src/camera`: 3인칭 및 향후 록온 카메라
- `src/world`: 지역, 절차적 표면, 분위기
- `src/ui`: 플레이어 HUD와 개발 진단
- `src/config`: 조정 가능한 수치
- `docs`: 제작 헌장, 아트, 전투, 보스, 차수 기록
- `tools`: 자동 검증

## 기술 원칙

- 물리와 판정은 렌더링 FPS에 종속시키지 않는다.
- 시각 메시와 충돌 메시를 분리한다.
- 전투 행동은 준비·활성·회복 구간을 데이터로 관리한다.
- 최종 화면의 UI와 개발 진단을 분리한다.
- 후처리와 투명 효과는 적의 예고 동작을 가리지 않는다.
- 외부 자산은 출처와 라이선스를 기록하지 않으면 포함하지 않는다.
