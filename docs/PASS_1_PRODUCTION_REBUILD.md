# Production Pass 1 — 대성당 진입로와 이동 기준

이 차수는 기존 이동 시험용 Pass 1을 출시작 기준으로 대체한다.

## 구현

- 대성당 진입로를 실제 게임 지역의 첫 구간으로 재구성
- 절차적으로 생성한 석재 색상·균열·거칠기 텍스처
- 달빛, 횃불 점광원, 잿가루 입자, 낮은 안개층
- 색 보정, 비네팅, 약한 필름 그레인 후처리
- 계층형 갑옷 기사 리그와 대기·걷기·질주·낙하 동작
- 키보드·마우스, 일반 게임패드 이동과 시점 입력
- 클릭 포인터 고정과 드래그 시점의 동시 지원
- 속도 기반 카메라 선행, 어깨 오프셋, 질주 FOV, 장애물 당김
- 고정 물리 스텝의 최대 보정 횟수 제한
- 플레이어용 HUD와 F3 개발 진단 분리

## 다음 차수로 넘기지 않은 항목

공격, 회피, 체력과 스태미나의 실제 소모는 Production Pass 2에서 하나의 행동 상태 시스템으로 구현한다. 현재 HUD 막대는 레이아웃 기준이며 아직 자원 시스템과 연결되지 않았다.
