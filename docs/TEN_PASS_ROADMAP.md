# 10차 제작 로드맵

## 진행 상태

- Pass 0: 기반 구축 완료
- Pass 1: 3인칭 이동과 추적 카메라 완료
- 다음 작업: Pass 2 회피와 스태미나

## 최종 범위

- 플레이 시간 약 8~12분
- 연결된 소규모 성역 지역 1개
- 일반 적 2종
- 정예 적 1종
- 체크포인트 1개와 지름길 1개
- 2페이즈 보스 1명
- 키보드·마우스 중심 조작, 게임패드 확장 가능 구조

## 1차 — 3인칭 이동의 감각

플레이어 캡슐 충돌, 걷기, 달리기, 방향 전환, 경사면, 중력, 계단 처리와 추적 카메라를 구현한다. 목표는 전투 이전에 이동만으로도 불쾌한 미끄러짐과 카메라 끼임이 없게 만드는 것이다.

## 2차 — 회피와 스태미나

구르기, 무적 구간, 달리기 소모, 스태미나 회복 지연을 구현한다. 입력 연타로 무한 회피가 되지 않게 하되, 적 공격 뒤에 반격할 여유를 남긴다.

## 3차 — 플레이어 공격

약공격 3연계, 강공격, 공격 중 이동 제한, 히트박스, 경직, 타격 정지를 구현한다. 임시 무기와 훈련용 표적을 사용해 거리와 타이밍부터 검증한다.

## 4차 — 록온과 전투 카메라

시야 내 표적 선택, 표적 전환, 록온 이동, 카메라 장애물 회피를 구현한다. 적이 화면 밖으로 밀려나거나 카메라가 바닥을 향하는 문제를 우선 수정한다.

## 5차 — 일반 적 AI

순찰, 감지, 접근, 견제, 공격, 후퇴, 경직, 사망 상태를 갖는 근접 적을 만든다. 두 번째 적은 공격 속도와 사거리를 달리해 같은 대응만 반복하지 못하게 한다.

## 6차 — 소울라이크 순환 구조

체력, 회복약, 체크포인트, 적 재생성, 사망, 재화 손실과 회수를 구현한다. 재도전 시간이 전투 시간보다 길어지지 않도록 동선을 조정한다.

## 7차 — 지역과 지름길

시작 성역, 폐허 길, 전투 광장, 우회 통로, 지름길, 보스 문을 하나의 지역으로 연결한다. 반복되는 상자형 방을 피하고 높낮이와 시야의 변화로 진행 방향을 보여준다.

## 8차 — 보스 1페이즈

보스 이동, 근거리 연계, 간격 벌리기 대응, 광역 예고, 체력 UI를 구현한다. 공격 예고를 읽을 수 있게 하면서 단순히 뒤로 구르기만 해서는 이기기 어렵게 만든다.

## 9차 — 보스 2페이즈와 연출

체력 조건에 따른 전환, 새로운 패턴, 효과, 사운드, 승리 흐름을 구현한다. 1페이즈의 규칙을 완전히 버리기보다 변형해 학습이 이어지도록 한다.

## 10차 — 출시형 데모 정리

난이도, 입력 버퍼, 판정, 성능, UI, 시작 화면, 엔딩, 크레딧, 브라우저 호환을 정리한다. 자동 검증과 실제 Pages 배포를 확인한 커밋을 최종 기준점으로 만든다.

## 매 차수 완료 조건

1. `npm run verify` 통과
2. 해당 차수의 플레이 가능한 변화 확인
3. 이전 기능의 회귀 오류 확인
4. 문서에 조절 수치와 알려진 한계 기록
5. 증분 Git bundle 생성 가능 상태 유지
