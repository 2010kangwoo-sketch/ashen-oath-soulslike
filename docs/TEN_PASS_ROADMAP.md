# 출시작 10차 제작 로드맵

기존의 8~12분 기능 데모 계획은 폐기한다. 목표는 첫 클리어 45~70분 분량의 짧은 완결형 3D 소울라이크다. 한 차수는 단순히 기능 하나를 추가하는 것이 아니라 해당 기능을 출시 수준까지 다듬는 단위다. 최종 빌드에는 보스 3명과 완결된 엔딩이 반드시 포함된다.

## 진행 상태

- Pass 0: 빌드·배포 기반
- Production Pass 1: 출시 범위·아트 방향·이동·카메라·첫 지역 시각 기준
- Production Pass 2: 체력·스태미나·회피·방어·패링·록온과 기본 전투
- Production Pass 3: 장검 3연계·차지·자세 붕괴·처형·물리 기반 적 이동
- Production Pass 4: 여성 주인공 리그와 다중 관절 머리카락·몸짓
- Production Pass 5: 세 구역 연결, 서약석·지름길·사망·재 회수, 적 4종·정예 2종
- Production Pass 6: 문지기 바르칸 전용 경기장, 안개문, 방패 대응과 2페이즈 보스전
- Production Pass 7: 종을 삼킨 과부, 수직 경기장, 파괴 가능한 종, 직선·도넛·다중 원점 기믹
- Production Pass 8: 재의 서약자 3페이즈, 잔상·왕관 기믹, 재의 왕좌, 두 결말과 크레디트
- Production Pass 9: 시작·일시정지 메뉴, 손상 방지 자동 저장, 이어하기, 그래픽·음량·카메라·조작 안내 설정
- Release Candidate Pass 10: 엔딩 저장과 종료 동선, 브라우저 복구, 접근성, 성능·진행 회귀 검증

## 1차 — 제작 방향 재설정과 이동 완성

시험장 형태를 실제 첫 지역인 대성당 진입로로 교체한다. 플레이어 최종 스타일 리그, 절차적 표면, 후처리, 입자, 조명, 키보드·마우스와 게임패드 이동, 포인터 고정 시점, 카메라 충돌과 질주 FOV를 구현한다.

## 2차 — 회피·방어·패링과 전투 자원 완료

체력과 스태미나, 질주 소모, 구르기 무적 시간, 전방 방어와 스태미나 파괴, 패링 창을 데이터로 분리했다. 약공격 2연계, 강공격, 록온, 타격 효과와 잿빛 파수병의 3개 공격을 실제 전투로 연결해 입력 버퍼와 행동 우선순위를 검증했다.

## 3차 — 장검 전투와 물리 연출 완성

약공격 3연계, 차지 강공격, 제한된 공격 방향 보정, 히트 스톱, 자세 붕괴와 처형을 구현했다. 기사형 적의 좌표 이동을 Rapier 충돌 이동으로 바꾸고 사냥개형 적을 추가했다. 동적 잔해, 발소리와 무게별 전투음, 자세·처형 HUD를 실제 전투에 연결했다.

## 4차 — 여성 주인공 리그와 2차 움직임 완료

여성 서약지기 비율로 전신 리그를 교체하고 얼굴·시선·눈 깜빡임을 구현했다. 앞머리, 옆머리, 후두부 층, 긴 묶은 머리를 9개 묶음과 41개 관절로 나누어 이동·회전·낙하·회피·공격·피격에 반응시켰다.

## 5차 — 레벨 전체 구조와 소울 순환 완료

대성당 진입로, 종루 회랑, 잿빛 제단을 하나의 물리 공간으로 연결했다. 서약석 3개, 지름길 3개, 사망·적 재생성·재화 손실과 회수·회복병 충전을 구현했다. 검병·창병·종지기·사냥개의 네 일반 적과 패턴이 다른 정예 2종, 동시 공격 슬롯 규칙을 완성했다.

## 6차 — 보스 1 문지기 바르칸 완료

서약의 문 앞뜰과 안개문, 전용 보스 HUD를 추가했다. 1페이즈는 정면 방패 방어, 방패 돌진, 방패 내려찍기와 3연격을 사용한다. 강공격과 후방 공격으로 방패 내구도를 깎거나 체력을 55%까지 낮추면 방패가 실제 물리 잔해로 튕겨 나가며 2페이즈로 전환된다. 2페이즈는 광란 4연격, 물리 도약 내려찍기, 서약불 휩쓸기와 교차 베기를 사용한다. 사망 시 보스와 안개문이 초기화되고 마지막 서약석에서 바로 재도전할 수 있다.

## 7차 — 보스 2 종을 삼킨 과부 완료

공허한 종의 심장과 전용 안개문을 추가했다. 과부는 천장과 지상을 오가며 낙하 그림자, 직선 실 장벽, 다중 종 음파, 연속 낙하, 실창, 돌진과 도넛형 전장 공격을 사용한다. 세 개의 종은 별도의 파괴 대상이며 종이 끊어지거나 체력이 임계점에 도달하면 2페이즈로 전환된다. 수직 록온 프레이밍, 기믹 경고 HUD, 보스 상태에 반응하는 블룸·색수차·비네트도 연결했다.

## 8차 — 보스 3 재의 서약자와 결말

플레이어와 같은 장검 규칙을 사용하는 여성 최종 보스를 3페이즈로 구현했다. 1페이즈는 정통 검술과 반격, 2페이즈는 플레이어 이동을 읽는 잔상 협공, 3페이즈는 왕관 낙하·도넛·직선·연속 검격 기믹으로 구성한다. 재의 왕좌에서 서약을 계승하거나 끊는 두 결말과 전용 문구·후처리·크레디트를 연결했다.

## 9차 — 메뉴·옵션·저장 완료

시작 화면, 이어하기, 새 서약, 일시정지와 마지막 서약석 재시작을 구현했다. 자동 저장은 보스 처치, 재 획득·회수, 서약석 활성화, 지름길 개방과 사망 시 즉시 실행되며, 30초 단위 플레이 시간도 기록한다. 저장 데이터는 버전·보스 진행 순서·좌표·ID를 검증해 손상된 값이 게임 상태로 들어오지 않게 한다. 성능·균형·시네마틱 그래픽 프리셋, 전체 음량, 카메라 충격, 마우스 감도와 조작 안내 설정을 제공한다.

## 10차 — 출시 후보 검증

엔딩 선택이 실제 저장에 남고 크레디트 이후 시작 화면이나 새 게임으로 이동할 수 있게 수정했다. 브라우저가 숨겨지면 자동으로 저장·일시정지하며 WebGL 문맥 손실 시 저장 후 복구한다. 움직임 감소, 3D 보스 바닥 전조 강조, UI 크기 옵션을 추가하고 카메라 프레임당 임시 벡터 할당을 제거했다. 게임패드 메뉴 이동과 기존 기록 삭제 확인 절차를 연결하고, 개발용 초기화·진단 키는 `?debug` 주소에서만 활성화한다. 출시 경로·HTML ID·저장·설정·세 보스 회귀 검사를 통과한 빌드를 `1.0.0-rc.1`로 지정한다.

## 매 차수 완료 조건

1. `npm run verify` 통과
2. 해당 차수 기능을 실제 플레이 가능한 형태로 제공
3. 이전 차수의 핵심 동작 회귀 검사
4. 1080p 성능과 메모리 확인
5. 임시 오브젝트와 개발 문구를 최종 화면에서 제거
6. 알려진 한계와 다음 차수에서 해결할 항목 기록
7. 증분 Git bundle 검증 및 깨끗한 저장소에서 fast-forward 재현
