# 전투와 보스 설계 기준

## 플레이어 전투의 중심

주무기는 한손 장검이다. 공격 수를 늘리기보다 거리, 선입력, 회복 시간, 방향 전환의 차이를 명확히 한다.

- 약공격 3연계: 빠른 확인 공격 → 전진 베기 → 넓은 마무리
- 강공격: 느리지만 자세 피해가 높고 약한 적을 밀어냄
- 회피: 짧은 무적 시간과 명확한 후딜레이
- 방어: 안정적이지만 스태미나 손실이 큼
- 패링: 위험하지만 성공 시 큰 자세 피해
- 회복: 이동은 가능하되 속도가 낮아지고 쉽게 끊김

입력 버퍼, 취소 가능 구간, 히트 스톱, 카메라 흔들림, 효과음은 수치표로 관리한다. 애니메이션만 보고 판정을 추측하게 두지 않는다.

## 보스 1 — 문지기 바르칸

검과 방패를 든 인간형 보스. 기본 전투 규칙을 시험한다.

- 느린 3연격과 빠른 방패 치기 사이의 박자 변화
- 플레이어가 뒤로만 빠지면 사용하는 돌진
- 방패를 계속 때리면 반격하지만, 강공격과 패링으로 자세를 무너뜨릴 수 있음
- 2페이즈에는 방패를 버리고 공격 범위와 연계가 늘어남

## 보스 2 — 종을 삼킨 과부

천장과 기둥을 이용하는 비인간형 보스. 카메라와 공간 인식을 시험한다.

- 천장 이동 후 낙하 위치를 바닥 그림자와 종소리로 예고
- 실을 설치해 이동 경로를 제한하지만 완전한 막다른길은 만들지 않음
- 플레이어가 가까이 머물면 몸통 휩쓸기, 멀어지면 음파 공격
- 종을 끊으면 일부 패턴이 약해지지만 새로운 근접 패턴이 열림

## 보스 3 — 재의 서약자

플레이어와 같은 장검 체계를 사용하는 최종 보스. 지금까지 배운 규칙을 변형한다.

- 플레이어의 회피 방향을 읽고 마무리 방향을 바꾸는 연계
- 무조건 추적하는 것이 아니라 거리와 스태미나를 관리함
- 2페이즈에는 이전 두 보스의 규칙을 복사하지 않고, 잿불 분신으로 공격 시작 시점만 교란함
- 마지막 체력 구간은 속도 증가보다 회복 가능 시간과 공간을 줄이는 방식으로 긴장감을 높임

## 보스 패턴 완료 조건

각 공격은 준비, 활성, 회복의 세 구간이 데이터로 분리되어야 한다. 최소 3회 연속 플레이 테스트에서 같은 입력에 다른 판정이 나오면 완료로 보지 않는다.
