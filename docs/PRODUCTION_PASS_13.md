# Production Pass 13 — 최종 이동·충돌·런타임 안전성

Pass 13은 기능 추가 차수가 아니라 출시 차단 위험을 줄이는 최종 품질 패스다. 자동 검사는 실제 완주를 대체하지 않으며, 배포 빌드의 수동 완주 전에는 정식 `1.0.0`으로 승격하지 않는다.

## 이동 안전망

- 플레이어가 정상적인 범위 안에서 움직일 때 위치를 강제로 보정하지 않는다.
- 접지 상태의 최근 안전 위치를 짧은 간격으로 순환 기록한다.
- NaN·무한대 좌표, 전체 플레이 영역 이탈, 한 프레임의 비정상 대이동만 실패로 판정한다.
- 실패 시 화면을 가린 뒤 최근 안전 위치로 복귀한다. 안전 기록이 없으면 마지막 서약석을 사용한다.
- 복구는 체력·재·회복병·기술 쿨타임을 임의로 초기화하지 않는다.
- 일시정지 메뉴에서 사용자가 직접 `최근 안전 지점으로 복구`를 선택할 수 있다.

## 물리 프레임 안전성

- 탭 복귀나 일시적인 정지로 큰 delta가 들어와도 한 프레임 최대 서브스텝 수를 넘기지 않는다.
- 처리하지 못한 시간을 다음 프레임에 무한 누적하지 않는다.
- 화면 전환, 일시정지, 부활, WebGL 문맥 손실과 복구에서 물리 누적기를 초기화한다.
- 개발 진단창에 최근 스텝 수, 누적 포화 횟수와 버린 시간을 표시한다.

## 보스 경기장 경계

- 바르칸, 종을 삼킨 과부, 재의 서약자는 각 전용 경기장 범위 안에서만 이동한다.
- 유효하지 않은 좌표나 경기장 아래 낙하가 감지되면 체력과 페이즈를 유지한 채 중앙 안전 위치로 복귀한다.
- 복귀 시 진행 중 공격 큐와 전조를 정리해 보이지 않는 판정이 남지 않게 한다.

## 입력 장치 수명주기

- 첫 번째 배열 슬롯이 아니라 실제 연결된 게임패드를 선택한다.
- 플레이 중 게임패드가 분리되면 키보드·마우스로 즉시 전환할 수 있다.
- 같은 게임패드 또는 다른 게임패드가 재연결되면 페이지를 새로고침하지 않고 다시 인식한다.
- 진단창에 마지막으로 사용한 입력 장치와 게임패드 이름을 표시한다.

## 실행과 검증

- `run-game.ps1`: Node.js 버전과 의존성을 확인한 뒤 로컬 서버를 열어 게임을 실행한다.
- `verify-and-preview.ps1`: 타입 검사, 프로덕션 빌드, Pass 13 검증을 통과한 결과물만 미리보기로 연다.
- `npm run verify`: 실제 의존성이 설치된 환경에서 타입 검사와 Vite 빌드를 필수로 수행한다.

## 수동 출시 차단 항목

다음 항목은 자동 코드 검사만으로 통과 처리하지 않는다.

- 새 게임부터 두 결말까지 키보드·마우스 완주
- 게임패드 완주와 플레이 중 연결 해제·재연결
- 모든 벽·문·기둥·계단·경사·보스 경기장 경계 탐색
- Chrome·Edge·Firefox 실행과 저장 복구
- 30분 이상 플레이의 평균·95백분위 프레임 시간과 메모리 추세
- 밝기, 그림자, 기술 모션, 카운터 전조와 실제 판정의 체감 일치
