# Ashen Oath 최종 품질 보증표 — Pass 11~13

이 문서는 기능 존재 여부가 아니라 실제 플레이 품질을 판정한다. 자동 검사는 구조와 회귀를 찾는 도구일 뿐이며, 아래에서 수동 확인으로 지정된 항목은 배포 빌드 완주 없이 통과 처리하지 않는다.

## 추가 품질 기준

### 전투 공정성

- 공격 전조와 실제 판정의 시작·종료 프레임이 일치한다.
- 카메라 밖 공격은 음향 또는 방향 경고가 있다.
- 한 번의 피격으로 연속 경직이 확정되지 않도록 무적·밀림·적 공격 슬롯을 검증한다.
- 안전지대와 위험지대의 시각 효과가 실제 판정보다 작지 않다.

### 입력과 접근성

- 키보드 동시 입력, 낮은 키보드 반복률, 게임패드 데드존과 분리·재연결을 확인한다.
- UI 90~125%, 공격 전조 강조, 움직임 감소에서 기능 정보가 사라지지 않는다.
- 1366×768에서도 기술 HUD·보스 HUD·메뉴가 겹치지 않는다.

### AI와 경계

- 적은 안개문·닫힌 문·낙하 경계 밖으로 추격하지 않는다.
- 소환 적과 일반 적의 동시 공격 수가 제한된다.
- 보스가 지형에 밀려 경기장 밖으로 나가거나 기둥 안에 고정되지 않는다.
- 플레이어가 비정상 위치에 있을 때 AI가 무한 공격·무한 회전 상태에 빠지지 않는다.

### 성능과 메모리

- 30분 이상 플레이 후 드로우콜·삼각형·GPU 메모리·프레임 시간이 지속 증가하지 않는다.
- 보스 재도전과 새 게임 반복 후 파티클, 광원, 이벤트 리스너와 물리 강체가 중복되지 않는다.
- 탭 전환 뒤 큰 delta가 물리와 쿨타임을 한 번에 건너뛰지 않는다.
- 품질 자동 조절이 짧은 히트 스톱이나 화면 전환을 성능 저하로 오인하지 않는다.

### 저장·배포

- 이전 RC 저장을 새 RC에서 열 때 진행이 보존되거나 명확히 초기화된다.
- 저장 중 탭 종료, 저장소 용량 부족과 손상 JSON을 시험한다.
- Chrome, Edge, Firefox에서 시작·포인터 잠금·게임패드·오디오 해제가 동작한다.
- 직접 경로 새로고침, WebGL 문맥 손실, 창 크기와 DPI 변경을 확인한다.

## 최종 판정 규칙

- Pass 11~13의 자동 검사를 모두 통과해도 수동 완주가 끝나지 않으면 `1.0.0`으로 승격하지 않는다.
- 진행 차단, 저장 손실, 벽 관통, 보스 판정 불일치 또는 브라우저 빌드 실패는 즉시 출시 차단 등급이다.
- 프레임·밝기·카메라·난이도는 테스트 장치와 장면을 기록하고 수정 전후 같은 경로로 비교한다.
