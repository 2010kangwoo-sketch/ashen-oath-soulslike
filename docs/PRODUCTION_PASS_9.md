# Production Pass 9 — 출시용 메뉴, 저장과 품질 설정

이번 차수는 새 전투 콘텐츠를 추가하지 않고, 완결된 게임을 실제 사용자가 시작하고 중단하고 다시 이어 갈 수 있도록 제품 계층을 완성한다.

## 시작 및 일시정지 흐름

- 로딩 완료 뒤 즉시 전투 입력을 받지 않고 전용 시작 화면을 표시한다.
- 이어하기는 유효한 저장 파일이 있을 때만 활성화한다.
- 새 서약은 이전 진행 저장만 제거하고 사용자의 그래픽·음량 설정은 보존한다.
- Esc 일시정지 중에는 입력, Rapier 고정 스텝, 적 AI와 진행 시간이 멈춘다.
- 메뉴가 열리면 포인터 고정을 해제하고 전투 음량을 낮춘다.
- 마지막 서약석 재시작은 보유 재를 임의로 삭제하지 않고 휴식 규칙에 맞게 적과 회복병을 초기화한다.

## 저장 규칙

저장 데이터는 `localStorage`의 버전 1 스키마를 사용한다.

- 마지막 활성 서약석과 활성화한 서약석 목록
- 열린 지름길
- 보유 재와 회수 대기 중인 재의 위치
- 세 보스의 처치 상태
- 확인한 결말 종류
- 플레이 시간

다음 사건은 즉시 자동 저장한다.

- 재 획득 또는 회수
- 서약석 활성화
- 지름길 개방
- 사망으로 재를 떨어뜨림
- 보스 처치 보상 반영

그 외에는 30초 단위 플레이 시간과 상태 변화가 있을 때만 저장한다. 매 프레임 또는 1초마다 저장하지 않아 브라우저 저장소 쓰기와 화면 알림이 과도하게 반복되지 않는다.

## 손상 방어

- 저장 버전이 다르면 이어하기에 사용하지 않는다.
- 알려진 서약석과 지름길 ID만 복원한다.
- 좌표가 숫자 세 개가 아니면 회수 재 위치를 폐기한다.
- 보스 진행 순서는 바르칸 → 과부 → 재의 서약자 순서가 깨지지 않도록 정규화한다.
- 저장소 접근이 차단되거나 용량 오류가 발생해도 현재 세션은 중단하지 않는다.

## 설정

- 그래픽: 성능 우선, 균형, 시네마틱
- 전체 음량
- 카메라 타격 충격
- 마우스 시점 감도
- 화면 조작 안내 표시

그래픽 프리셋은 렌더 픽셀 비율, 그림자 필터, 블룸, 비네트와 필름 입자 상한을 함께 조절한다. 프레임이 5초 이상 38 FPS 아래에 머물면 내부 렌더 배율을 단계적으로 낮추고, 14초 이상 안정적으로 55 FPS를 넘으면 서서히 복구한다. 카메라 충격을 0으로 설정해도 전투 판정과 애니메이션에는 영향을 주지 않는다.

## 알려진 범위

이번 차수에서는 키보드 키를 임의로 재지정하는 기능과 다중 저장 슬롯을 넣지 않았다. 두 기능은 전체 회귀 검증보다 우선할 정도로 안정화되지 않았으므로, Pass 10에서는 먼저 완주 가능성·저장 복원·브라우저 호환·성능을 검증한다.
