# Ashen Oath 제작 헌장

이 프로젝트는 기술 시험이나 연습용 데모가 아니다. 10차 작업의 결과물은 시작 화면부터 엔딩과 크레딧까지 존재하고, 무료 또는 유료로 공개해도 부끄럽지 않은 짧은 완결형 3D 소울라이크 게임이어야 한다.

## 출시 범위

- 목표 플레이 시간: 첫 클리어 45~70분
- 하나로 연결된 지역: 대성당 진입로, 종루 회랑, 잿빛 제단
- 일반 적 4종, 정예 적 2종
- 규칙과 대응법이 서로 다른 보스 3명
- 체크포인트 3개, 지름길 3개
- 주무기 1종을 깊게 완성하고 공격·회피·방어·패링을 모두 지원
- 저장, 옵션, 일시정지, 사망·재화 회수, 엔딩, 크레딧
- 키보드·마우스와 일반 게임패드 지원

## 절대 타협하지 않는 기준

1. 어려움은 불분명한 판정이나 카메라 방해가 아니라 읽을 수 있는 예고와 선택의 압박에서 나온다.
2. 공격 모션, 실제 히트박스, 무적 시간, 효과음이 같은 순간을 가리켜야 한다.
3. 보스는 단순한 체력 많은 일반 적이 아니며, 각자 하나 이상의 고유 규칙을 가진다.
4. 같은 벽·기둥·방을 복사해 길이를 늘리지 않는다.
5. 최종 화면에 개발용 시험장, 진단 패널, 임시 문구를 노출하지 않는다.
6. 라이선스가 불명확한 모델·음악·효과음을 사용하지 않는다.
7. 성능 문제를 마지막 차수로 미루지 않는다. 매 차수에서 1080p 기준 성능을 확인한다.

## 현재 아트 방향

실사 흉내를 내다 저품질로 보이는 방향을 피하고, 거친 금속과 깎인 석재의 면을 강조하는 다크 판타지 스타일을 사용한다. 절차적 메시와 텍스처도 최종 미술 규칙에 맞춰 제작하며, 단순 상자와 캡슐을 최종 그래픽처럼 남겨 두지 않는다.
